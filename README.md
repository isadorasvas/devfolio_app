
# DevFolio App

Projeto final da disciplina PPDM, desenvolvido utilizando Flutter.

## Sobre o projeto

O DevFolio App é um aplicativo de portfólio pessoal que apresenta informações sobre o desenvolvedor, suas habilidades, projetos e métricas de aprendizado.

## Componentes desenvolvidos

- **CartaoPerfil:** apresenta as informações pessoais e acadêmicas.
- **DashboardMetricas:** mostra os indicadores do portfólio.

## Tecnologias utilizadas

- Flutter
- Dart
- Material Design 3

## Acessibilidade

O aplicativo possui:

- Textos com boa legibilidade.
- Contraste entre texto e fundo.
- Ícones acompanhados de informações textuais.
- Rótulos semânticos para leitores de tela.
- Layout adaptável para diferentes tamanhos de tela.

## Como executar

1. Execute `flutter pub get`.
2. Execute `flutter run -d chrome`.
